# SYM Cocina y Repostería

Sitio estático listo para GitHub Pages. El archivo `index.html` y la carpeta `images` deben quedar en la raíz de la rama `main`. Activar Pages desde Settings → Pages, origen `Deploy from a branch`, rama `main`, carpeta `/ (root)`.

La imagen de lunchs aún es ilustrativa. Los botones de consulta abren WhatsApp con un mensaje predeterminado.
